# AI-Driven Entity Resolution & Data Quality Platform

Production-scale entity resolution engine for cloud lakehouses using probabilistic matching and ML scoring.

## Status

🚧 **Work in Progress** - Building MVP

## Overview

This platform solves the "golden record" problem for enterprise data systems: identifying when different records refer to the same real-world entity across multiple source systems.

## Tech Stack

- PySpark
- AWS Glue
- Apache Iceberg
- Splink (probabilistic matching)
- Great Expectations
- Python 3.9+
